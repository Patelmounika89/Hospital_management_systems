# Hospital Management System

## Project Description
The Hospital Management System is a Python and database-based project designed to manage patient records, doctor details, appointments, and billing information.

## Technologies Used
- Python
- PostgreSQL
- MongoDB
- SQL
- VS Code

## Project Modules

### 1. ER Diagram
Designed an ER diagram with the following entities:
- Patients
- Doctors
- Departments
- Appointments
- Bills

### 2. PostgreSQL
- Created Patients, Doctors, and Appointments tables.
- Inserted sample records.
- Implemented Primary Keys and Foreign Keys.

### 3. SQL Queries
Implemented queries using:
- SELECT, INSERT
- GROUP BY, HAVING
- ORDER BY, LIMIT
- COUNT(), SUM(), MAX()
- INNER JOIN and LEFT JOIN

### 4. MongoDB
Created two collections:
- Patients
- Appointments

Performed CRUD operations:
- insertOne()
- insertMany()
- find()
- updateOne()
- deleteOne()

Also implemented city-wise patient counting using Aggregation.

### 5. Python OOP
Implemented:
- Classes and Objects
- Constructors
- Inheritance
- Encapsulation

### 6. Menu-Driven Program
Implemented the following operations:
1. Add Patient
2. View Patients
3. Search Patient
4. Exit

Used Python functions, loops, and conditional statements.
